## Installation

1. **Download the Files:** Save all extension files into a single folder on your computer (e.g., `/Dark-Weather-New-Tab`).
2. **Open Extensions:** Open your browser and navigate to the **Manage Extensions** page (usually found at `chrome://extensions/` or `edge://extensions/`).
3. **Enable Developer Mode:** Toggle on **Developer mode**.
4. **Load the Extension:** Click **Load unpacked** and select the folder where you saved the files.
